🛠️ Perbaikan Koneksi Google Sheets

Portal Tribik Auction gagal menyimpan ke spreadsheet karena deployment Apps Script kehilangan fungsi doPost. Ikuti 4 langkah di bawah — sekitar 5 menit.

⏳ Menguji endpoint saat ini…

1 & 2 · Salin kode backend, lalu tempel ke Apps Script spreadsheet

🔗 Buka Spreadsheet
  1. Klik Salin Kode Backend di atas.
  2. Di spreadsheet: Ekstensi → Apps Script.
  3. Hapus semua isi editor, tempel (Ctrl+V), lalu Save 💾.
Lihat kode (gsheet_backend.gs)
memuat…

3 · Deploy ulang (wajib setelah kode ditempel)

  1. Deploy → Manage deployments → ✏️ Edit (ikon pensil).
  2. Version: New version · Who has access: Anyone · klik Deploy.
  3. URL boleh tetap sama — jika sama, langsung lanjut langkah 4.

💡 Jangan tekan tombol ▶️ Run di editor. Error "Attempted to execute myFunction, but it was deleted" itu aman & justru pertanda baik — fungsi template bawaan memang sudah terganti kode backend. Tombol Run tidak dipakai: doPost dipanggil otomatis oleh portal lewat HTTP. Yang dibutuhkan hanya Deploy di atas.

4 · Tes ulang — dan terapkan URL bila berubah

Tombol Terapkan otomatis memperbarui portal.html & firebase-config.js. Jika URL tetap sama, cukup Tes Ulang lalu buka portal dan submit.
